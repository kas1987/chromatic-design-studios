# Claude Design Scaffold Prompt

You are helping scaffold **Chromatic Design Studios**, a local-first AI design and operations control center.

## Goal
Create the initial UI and repo structure for a premium, cosmic, glassy, disciplined design studio interface.

## Required style
- Cosmic premium interface
- Holographic cards
- Clean white/black contrast with chromatic glow accents
- Soft gradients, glass, bloom, subtle motion
- Audit-friendly layouts
- No clutter
- No generic SaaS blandness

## Required screens
1. Dashboard
2. Asset Library
3. Prompt Studio
4. Model Router Matrix
5. Agent Queue
6. Service Health
7. Design Token Lab
8. PDR Browser

## Required components
- Sidebar navigation
- Top command bar
- Holographic card component
- Status badge
- Service health card
- Prompt card
- Agent queue row
- Model routing table
- Asset preview tile

## Constraints
- Use Next.js/React conventions.
- Prefer Tailwind and shadcn/ui style components.
- Keep components modular.
- Do not hard-code secrets.
- Do not invent backend APIs; stub them with typed mock data.
- Keep all visual language reusable through tokens.

## Deliverable
Implement the first dashboard shell and reusable component foundation. Leave clear TODOs for service integration.
