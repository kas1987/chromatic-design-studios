# Design QA Checklist

## Visual Consistency

- [ ] Colors align with token palette.
- [ ] Glow effects are purposeful, not decorative noise.
- [ ] Spacing is consistent.
- [ ] Typography hierarchy is clear.
- [ ] Motion is restrained and meaningful.

## Implementation Quality

- [ ] File names are clear.
- [ ] Component scope is bounded.
- [ ] CSS classes are reusable.
- [ ] No hidden dependency is assumed.
- [ ] Output can be handed to Claude Design or Cursor.

## Governance

- [ ] Confidence score recorded if execution occurred.
- [ ] Stop conditions respected.
- [ ] Risks logged.
- [ ] Next task proposed.
