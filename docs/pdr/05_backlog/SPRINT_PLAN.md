# Sprint Plan — MVP Scaffold

## Sprint Goal

Turn the scaffold into a working design operations kit that can be used by Claude Design, Cursor, Codex, or other agents.

## Sprint 1 Tasks

1. Complete visual language.
2. Complete token schema.
3. Create CSS bundle structure.
4. Create Claude Design bridge prompt.
5. Create OpenArt prompt library.
6. Create QA checklist.
7. Create one hero-page example.

## Definition of Done

- Every new file has a clear purpose.
- Every task has an owner and acceptance criteria.
- Tokens are reusable.
- Prompts are paste-ready.
- QA checklist can reject poor outputs.
