# Zelex Brand Reference

> Source: zelexdoll.com K-Series live page + HowieZZ editorial project (2026-06-05)

## Brand Mark
- Wordmark: `ZELEXDOLL` (uppercase, no spacing)
- Product line in scope: **K-Series** — marketed as "Korean girl-group–inspired"

## Palette
- Dark/near-black grounds, white/ivory text, high contrast — confirmed dark-mode-first brand
- Our editorial accent layer: **Noir + Gold** (see design system doc)

## Typography Reconciliation
- Live site: sans-serif
- Editorial direction: serif display + sans-serif body/labels
- Resolution: classic luxury-magazine pairing — Didot/Bodoni/Playfair for headlines, Helvetica Neue/Arial for UI

## Product Naming Convention
Format: `[head code] + [body code]`

| Example | Meaning |
|---|---|
| `KE01_1 + ZK168B` | Head KE01_1, 168cm B-cup body |
| `KE02_1 + ZK159D` | Head KE02_1, 159cm D-cup body |

Body code decoding: `ZK` + height + cup letter (B/C/D/E)

## Spec Label Format
```
Height: 168cm / 5ft5
Weight: [kg range]
Cup: B / C / D / E
Material: Silicone
Skeleton: [type]
Series: K-Series
```

## Nav Vocabulary
- Sections: SLE Doll · Fusion · Inspiration · K Series · About Us
- CTAs: **Shop All**, **Buy Now**
