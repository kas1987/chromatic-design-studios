# Design: Design Token → Tailwind Wiring

**Date:** 2026-05-27
**Status:** Approved
**Project:** Chromatic Design Studios — Wave 4 Scaffold

---

## Problem

The `apps/web/tailwind.config.ts` contains four hardcoded hex values (`#0a0a0f`, `rgba(255,255,255,0.05)`, etc.) with no connection to the five JSON token files in `packages/tokens/src/`. The CSS library files (`chromatic-base.css`, `chromatic-effects.css`, etc.) cannot share those values. This violates Design Law #1: Token-Driven.

---

## Goal

Single physical source of truth: the JSON token files in `packages/tokens/src/`. Both the CSS library and Tailwind compile-time utilities derive their values from those files — no duplication, no hardcoded values downstream.

---

## Architecture

```
packages/tokens/
  src/
    colors.json          ← source of truth (mirrors 02_design_tokens/)
    spacing.json
    typography.json
    motion.json
    effects.json
  build.ts               ← NEW: JSON → CSS custom properties compiler
  dist/
    chromatic-tokens.css ← NEW: generated, gitignored
  package.json           ← add build + dev scripts

apps/web/
  src/app/globals.css    ← add @import "@chromatic/tokens/dist/chromatic-tokens.css"
  tailwind.config.ts     ← replace hardcoded hex with var(--token-name) references
```

## CSS Custom Property Naming Convention

The build script flattens nested JSON into `--{domain}-{key}` CSS vars:

| Token domain | JSON path | CSS var |
|---|---|---|
| Color — palette | `colors.primary.500` | `--color-primary-500` |
| Color — semantic | `colors.background.default` | `--color-background-default` |
| Color — text | `colors.text.primary` | `--color-text-primary` |
| Color — border | `colors.border.focus` | `--color-border-focus` |
| Color — semantic states | `colors.semantic.success` | `--color-semantic-success` |
| Spacing — scale | `spacing.scale.4` | `--space-4` |
| Spacing — gap | `spacing.semantic.gap.md` | `--space-gap-md` |
| Spacing — radius | `spacing.semantic.radius.lg` | `--radius-lg` |
| Typography — family | `typography.family.heading` | `--font-heading` |
| Typography — size | `typography.scale.xl.size` | `--text-xl` |
| Motion — duration | `motion.duration.*` | `--duration-*` |
| Motion — easing | `motion.easing.*` | `--ease-*` |
| Glow / effects | `effects.*` | `--glow-*` |

All vars are emitted inside `:root { ... }` in `dist/chromatic-tokens.css`.

---

## Build Script: `packages/tokens/build.ts`

- Reads each `src/*.json` at runtime using `fs/promises`
- Flattens nested objects recursively with `{domain}-{key}` separator (skipping non-leaf keys)
- Writes `dist/chromatic-tokens.css` containing:
  ```css
  /* Auto-generated by build.ts — do not edit */
  :root {
    --color-primary-500: #8b5cf6;
    --color-background-default: #0a0a0f;
    /* … all tokens … */
  }
  ```
- Exits non-zero if any source file is missing or malformed JSON
- Run with `tsx build.ts` (no compilation step needed)

### Flattening logic

- `colors.primary.500` → `--color-primary-500`
- `spacing.semantic.gap.md` → `--space-gap-md` (domain alias: `spacing` → `space`)
- `spacing.semantic.radius.lg` → `--radius-lg` (strip `spacing.semantic.` prefix for radius keys)
- `typography.family.heading` → `--font-heading` (domain alias)
- `typography.scale.xl.size` → `--text-xl` (take `.size` leaf, key becomes scale name)
- Non-value objects (e.g., `typography.scale.xl` containing `size`, `rem`, `lineHeight`) are flattened individually — only the `size` (px) value is emitted as `--text-{scale}`; `lineHeight` becomes `--leading-{scale}`

## `apps/web` Changes

Replace the current `theme.extend.colors` (4 hardcoded values) with the full token map using `var()` references:

```ts

    DEFAULT: 'var(--color-background-default)',
    elevated: 'var(--color-background-elevated)',
    overlay: 'var(--color-background-overlay)',

    DEFAULT: 'var(--color-surface-default)',
    hover: 'var(--color-surface-hover)',

  primary: {
    50: 'var(--color-primary-50)',
    100: 'var(--color-primary-100)',
    // … through 950
    500: 'var(--color-primary-500)',

  accent: { /* same pattern */ },

### `src/app/globals.css`

Add at the top (before Tailwind directives):

```

## Root `package.json` Changes

Add predev/prebuild lifecycle hooks so tokens regenerate before the web app:

```json
"scripts": {
  "predev":   "pnpm --filter @chromatic/tokens build",
  "prebuild": "pnpm --filter @chromatic/tokens build"
}
```

---

## `dist/chromatic-tokens.css` Gitignore

Add to `packages/tokens/.gitignore` (or root `.gitignore`):

```
packages/tokens/dist/
```

The file is generated at build time, not committed.

## Acceptance Criteria

| ID | Criterion |
|---|---|
| TC-01 | `pnpm --filter @chromatic/tokens build` exits 0 and emits `dist/chromatic-tokens.css` |
| TC-02 | `dist/chromatic-tokens.css` contains `--color-primary-500: #8b5cf6` |
| TC-03 | `apps/web` dev server starts after `predev` runs without error |
| TC-04 | `bg-primary-500` Tailwind class resolves to `background-color: var(--color-primary-500)` in compiled CSS |
| TC-05 | No hardcoded hex values remain in `tailwind.config.ts` |
| TC-06 | CSS library files can reference `var(--color-primary-500)` without duplication |
