# Brand Manifest — Chromatic Design Studios

## Identity

Chromatic Design Studios is the design operations layer for the Chromatic Harness ecosystem: a repeatable system for generating beautiful, coherent, testable design assets and implementation prompts from minimal user input.

## Brand Voice

- **Precise** — Every token, spacing value, and color has a named purpose.
- **Cosmic** — The visual language draws from deep space, holography, and luminous energy.
- **Modular** — Components are atomic, reusable, and composable.
- **Premium** — No clutter, no noise. Every pixel earns its place.
- **Operational** — Design is a system, not an art project. Repeatability matters.

## Visual North Star

| Quality | We Are | We Avoid |
|---------|--------|----------|
| Color | Deep space blacks, violet/cyan accents, controlled glow | Unreadable neon clutter, random gradients |
| Typography | Inter headings, IBM Plex Sans body, deliberate hierarchy | Mixing more than 2 font families |
| Spacing | 8px grid, mathematical rhythm | Arbitrary margins and paddings |
| Motion | Subtle, purposeful, 150-500ms | Jarring transitions, motion for decoration |
| Effects | Holographic gradients, glassmorphism, glow | Excessive blur, unreadable overlays |

## Target Users

| User | Need |
|------|------|
| Human creative director | Minimal prompting, maximum design leverage |
| Claude Design | Clear implementation prompt and structured design specs |
| Cursor/Codex builder | File-level work packets and acceptance criteria |
| Visual agent | Stable visual north star and prompt library |
| QA/auditor agent | Objective criteria for design consistency |

## Success Metrics

- Design request can be routed from `getdesign.md`: 100%
- Token files exist for color, spacing, typography, motion, glow: 100%
- Generated design artifacts pass QA checklist: 90%+
