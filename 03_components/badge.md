# Badge

> **Status:** stable
> **Category:** Display
> **Counterpart:** `packages/ui/src/components/Badge.tsx`

Chromatic Badge — compact status pill. Tone variants cover the full status surface: default, primary, accent, success, warning, error.

## Tones

| Tone | Use |
|------|-----|
| default | Neutral labels |
| primary | Brand or feature callouts |
| accent | Secondary callouts (cyan) |
| success | Positive states |
| warning | Caution states |
| error | Destructive or failure states |

## Token references

| Property | Token |
|----------|-------|
| Background (primary) | `color.primary.600` |
| Background (accent) | `color.accent.500` |
| Background (success) | `color.semantic.success` |
| Text | `color.text.inverse` on filled; `color.text.secondary` on neutral |
| Radius | `radius.full` (pill) |
| Padding | `space.2` horizontal, `space.1` vertical |
